# Bugfix Report — 2026-05-28

Fixes for all 7 high-priority issues (原 `01-high-priority-fixes.md`，已全部完成并归档).

## Fixed Issues

### 1.1 CSP 安全策略缺失 🔴

- **文件**: [tauri.conf.json](../../apps/desktop/src-tauri/tauri.conf.json)
- **根因**: `"csp": null` — WebView 无脚本注入防护，hook 事件字段被恶意构造时存在 XSS 风险
- **修复**: 定义严格 CSP `"default-src 'self'; style-src 'self' 'unsafe-inline'; script-src 'self'; connect-src 'self' http://127.0.0.1:17878"`

### 1.2 DB 反序列化 panic 🔴

- **文件**: [db.rs:86-98](../../apps/desktop/src-tauri/src/db.rs#L86-L98)
- **根因**: `deserialize_agent_source`、`deserialize_agent_status`、`deserialize_event_type` 使用 `unwrap()`，数据库出现异常值时直接 panic
- **修复**:
  - 三个函数返回 `Result<T, String>`，用 `map_err` 包装错误信息（包含 corrupt 值）
  - 新增 `map_deser` helper 将 `Result<T, String>` → `rusqlite::Result<T>`
  - 4 个调用点（`get_session`、`get_events_for_session`、`list_all_sessions`、`list_sessions_with_pid`）全部使用 `Self::map_deser(Self::deserialize_*(...))?` 传播错误
- **新增测试**: `test_deserialize_corrupt_value_returns_error`、`test_deserialize_valid_values_succeed`

### 1.3 Event Server 锁强制 unwrap 🔴

- **文件**: [event_server.rs:240-248](../../apps/desktop/src-tauri/src/event_server.rs#L240-L248)
- **根因**: `event_server.db.lock().unwrap()` — Mutex 被 poison 后所有后续 `.lock()` 连锁崩溃
- **修复**: 改为 `match` 处理，poison 时记录 `log::error!` 并返回 500（参照 `commands.rs` 和 `process_checker.rs` 的作法）

### 1.4 process_pid 数据丢失 🟡

- **文件**: [db.rs](../../apps/desktop/src-tauri/src/db.rs)
- **根因**: events 表缺少 `process_pid` 列，`insert_event` 不写入，`get_events_for_session` 硬编码为 `None`
- **修复**:
  - events 表添加 `process_pid INTEGER` 列
  - `insert_event` 写入 `process_pid`
  - `get_events_for_session` 读取 `process_pid`
- **新增测试**: `test_event_process_pid_roundtrip` — 写入 `process_pid: Some(12345)` 然后读回验证

### 1.5 Event Server 无服务端错误日志 🟡

- **文件**: [event_server.rs:224-231](../../apps/desktop/src-tauri/src/event_server.rs#L224-L231)
- **根因**: `handle_event` 失败时错误仅返回给客户端，服务端无日志
- **修复**: 在 `Err(e)` 分支添加 `log::error!("event_server: handle_event: {}", e)`

### 1.6 Event Server 线程无法优雅关闭 🟡

- **文件**: [event_server.rs](../../apps/desktop/src-tauri/src/event_server.rs)
- **根因**: HTTP server 线程脱离（detach）运行，无 shutdown signal
- **修复**:
  - `EventServer` 添加 `shutdown: Arc<AtomicBool>` 字段
  - `run_server_loop` 在 `for` 循环开头检测 shutdown flag
  - 新增 `shutdown()` 和 `shutdown_signal()` 方法
  - `start` / `start_shared` 返回 `Arc<AtomicBool>` 供外部触发关闭

### 1.7 `list_active_sessions` 已不存在 🟡

- **文件**: [db_test.rs](../../apps/desktop/src-tauri/tests/db_test.rs)
- **根因**: 测试函数名 `test_list_active_sessions` 引用不存在的函数，虽然体调用 `list_all_sessions()` 能正确执行，但名称误导
- **修复**: 重命名为 `test_list_all_sessions`；确认 db.rs 中无 dead code
